# LinkedIn Candidate Screener Chrome Store Listing

## Extension name
LinkedIn Candidate Screener

## Short description
Open a LinkedIn profile, add the role, and get recruiter-ready candidate notes in seconds.

## Long description
LinkedIn Candidate Screener helps recruiters, HR teams, and founders hiring directly make faster first-pass screening decisions. Open a LinkedIn profile, paste the job description, optionally add a resume, and get a role-fit verdict, fit signals, gaps, interview checks, and copy-ready recruiter notes.

This is a focused screening tool, not a bulk sourcing platform. The first version is designed to help you move faster on candidate review without forcing you into a heavyweight recruiting workflow.

## Privacy disclosure
- The extension reads the visible content on the currently open LinkedIn profile page only after the user clicks to run a screen.
- Optional recent activity and external links are included only when the user chooses them.
- The extension does not silently crawl multiple profiles or run bulk background scraping.
- Resume text is only included when the user pastes it into the popup.
